# Markdown for Beginners

**A practical Markdown starter kit** for students, researchers, and first-time GitHub users. Learn headings, links, tables, code blocks, math, README files, and research notes by editing examples.

No Git, account, or programming experience is required. You can start right here in your browser.

## Start in five minutes

1. Open the [practice editor](start-here/practice.md). Type on the left; the result appears on the right.
2. Change the heading, add a bullet point, and make a word **bold**.
3. Keep the [Simple Cheat Sheet](cheat-sheets/simple.md) open beside you.
4. When you want the full story, read the [Beginner Handbook](handbooks/beginner-handbook.md).
5. Copy a [template](templates.md) and make it your own.

!!! tip "Want to keep your notes?"
    Markdown files are plain text ending in `.md`. Create `notes.md` in any text editor (VS Code is a good choice), paste in what you wrote, and you have a real Markdown file. The [setup guide](handbooks/setup-and-editors.md) shows how to preview it.

## Which editor?

| If you want... | Try |
|---|---|
| A file editor already familiar to many developers | VS Code |
| To edit a repository README online | GitHub's web editor |
| A personal linked-note library | Obsidian |
| A browser-based collaborative note | HackMD |
| A live-preview Markdown editor | Typora, MarkText, or a similar editor |
| Code, citations, and multi-format output | Quarto |

VS Code supports Markdown previews without an extra extension. See the [editors guide](handbooks/setup-and-editors.md) for more detail.

!!! note "Markdown looks slightly different in different tools"
    Basic Markdown travels well between editors. Math, footnotes, callouts, and citations can differ between GitHub Flavored Markdown, Obsidian, and Quarto. Check the tool where your document will be read.
