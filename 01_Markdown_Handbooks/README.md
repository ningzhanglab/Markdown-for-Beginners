# Markdown Handbooks

Use this folder when you want **explanations**, not just a quick lookup.

| File | Use it when... |
|---|---|
| `Markdown_Beginner_Handbook.pdf` | You want to learn Markdown from the beginning |
| `Markdown_Setup_and_Editors_Guide.pdf` | You need help with VS Code, GitHub, HackMD, StackEdit, Jupyter/Colab, Quarto, or Obsidian |

The handbook has 74 sections. Its opening **How to Use This Handbook** page tells you which ones to read first.

For quick syntax lookup, go to `../02_Markdown_Cheat_Sheets/`.
