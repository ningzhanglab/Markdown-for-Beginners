# Markdown for Beginners

**A practical Markdown starter kit** for students, researchers, and first-time GitHub users. Learn headings, links, tables, code blocks, math, README files, and research notes by editing examples.

No Git or programming experience is required. Most Markdown files work in a text editor without a compiler.

## Start in five minutes

1. Open [Markdown_First_Note.md](00_Start_Here/Markdown_First_Note.md), then click the **Raw** or edit view to see its plain-text syntax.
2. Change the heading, add a bullet point, and add **bold** text.
3. Keep the [Simple Cheat Sheet (PDF)](05_Markdown_Cheat_Sheets/Markdown_Simple_Cheat_Sheet.pdf) beside you.
4. For a complete introduction, read the [Beginner Handbook (PDF)](04_Markdown_Handbooks/Markdown_Beginner_Handbook.pdf) or [editable Markdown](04_Markdown_Handbooks/Markdown_Beginner_Handbook.md).
5. Copy a template and make it your own.

## Which editor?

| If you want... | Try |
|---|---|
| A file editor already familiar to many developers | VS Code |
| To edit a repository README online | GitHub's web editor |
| A personal linked-note library | Obsidian |
| A browser-based collaborative note | HackMD |
| A live-preview Markdown editor | Typora, MarkText, or a similar editor |
| Code, citations, and multi-format output | Quarto |

VS Code supports Markdown previews without an extra extension. See the [editor guide](04_Markdown_Handbooks/Markdown_Setup_and_Editors_Guide.md) for more detail.

**Portability note:** Basic Markdown travels well between editors. Math, footnotes, callouts, and citations can differ between GitHub Flavored Markdown, Obsidian, and Quarto. Check the renderer when sharing a document.

## About the formats

- **`.md`** — editable source, rendered on GitHub.
- **`.pdf`** — printable reading reference.
- **`.qmd`** — Quarto source (related to, but not the same as, plain Markdown).

Download the repository through **Code → Download ZIP** if you do not use Git.
