# Markdown for Beginners

**A practical Markdown starter kit** for students, researchers, and first-time GitHub users. Learn headings, links, tables, code blocks, math, README files, and research notes by editing examples.

No Git or programming experience is required. A Markdown file is plain text, so any text editor can open it and there is nothing to install or build.

**Prefer your browser?** Read everything, and practice with a live editor, at **<https://ningzhanglab.github.io/Markdown-for-Beginners/>**. Nothing to install.

## Start in five minutes

1. Open [Markdown_First_Note.md](00_Start_Here/Markdown_First_Note.md), then click the **Raw** or edit view to see its plain-text syntax.
2. Change the heading, add a bullet point, and add **bold** text.
3. Keep the [Simple Cheat Sheet (PDF)](02_Markdown_Cheat_Sheets/Markdown_Simple_Cheat_Sheet.pdf) beside you.
4. For a complete introduction, read the [Beginner Handbook (PDF)](01_Markdown_Handbooks/Markdown_Beginner_Handbook.pdf) or [editable Markdown](01_Markdown_Handbooks/Markdown_Beginner_Handbook.md).
5. Try the [practice exercises](00_Start_Here/Markdown_Practice_Exercises.md). If something does not look right, see [Why doesn't mine look right?](00_Start_Here/Markdown_Troubleshooting.md)
6. Copy a template and make it your own.

## Which editor?

| If you want... | Try |
|---|---|
| A file editor already familiar to many developers | VS Code |
| To edit a repository README online | GitHub's web editor |
| A personal linked-note library | Obsidian |
| A browser-based collaborative note | HackMD |
| A live-preview Markdown editor | Typora, MarkText, or a similar editor |
| Code, citations, and multi-format output | Quarto |

VS Code supports Markdown previews without an extra extension. See the [editor guide](01_Markdown_Handbooks/Markdown_Setup_and_Editors_Guide.md) for more detail.

**Portability note:** Basic Markdown travels well between editors. Math, footnotes, callouts, and citations can differ between GitHub Flavored Markdown, Obsidian, and Quarto. Check the renderer when sharing a document.
